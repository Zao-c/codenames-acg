# 可调选牌时间与独立干扰：已确认实施契约

用户已批准：干扰超时系统补一张并自动准备；干扰从本局完整作品池快照选；零手选等待补选，互换排除干扰与系统补位牌。早期 Round 9 提案不构成本轮新规则。

起点：main f4dba98，Round 10 分支 ad30492（PR #18），上线前生产 a73ad5a。独立工作区 .worktrees/staged-draft，分支 codex/cipai-staged-draft，保留原工作区。

## 状态机

planning → guide → draft → interference → sealed → playing。

双方队长确认才启动普通选牌计时。服务端到期冻结普通牌并开始独立干扰。双方准备且各有手选后，房间锁内一次完成互换、补齐、封存；房主沿用五秒倒计时开局。房主可沿用取消准备回到 planning。

不增加 confirming、swapping 状态。干扰超时用 interferenceClosed 标记并清除截止时间；仅缺手选时继续等待补选。重复确认不得重新互换。

| 设置 | 可选 | 新建默认 |
| --- | --- | --- |
| 选牌 | 180／240／300 秒，两种尺寸均可设置 | 5×5：180；6×6：300 |
| 干扰 | 30／60 秒／不限时（null） | 30 秒 |
| 随机互换 | 每队一张普通手选牌 | 新协议固定开启 |

保存后所有成员看到规则摘要。正式准备期间修改时长需先取消准备。普通选牌保留拖拽、抢夺、撤回、原子替换、书签及十秒保护；最后二十秒仅禁止抢对方牌，自家撤回、空闲领取和合法替换照旧。按后续反馈，恢复组牌完毕／取消完成：双方完成可提前进入独立干扰，单方完成不推进。自家调整只取消自家完成；抢牌同时取消被影响队伍的完成。

独立干扰阶段冻结普通牌，两位队长查看双方手选，从本局完整作品池快照选择一张干扰。投放前确认；未准备且未截止时可替换，截止前可取消准备。限时到期给未投放一方补合法随机干扰，双方自动准备；不限时等待操作。保留交接与房主取消。

零手选队伍只能从空闲候选补一张普通牌，不能抢冻结牌。未补选前不封存，不用系统牌代替互换。双方准备且各有手选后，从各自普通手选中随机抽一张交换归属，再补位封存，干扰和系统补位严格不参与抽样。

## 状态、权限与兼容

- RoomSettings.animeDraft 保存 version=2、selectionSeconds、interferenceSeconds。endsAt 表示当前阶段截止，不限时省略；stageVersion 防跨阶段旧请求。干扰从实际服务端转换时间起算，避免调度延迟吞掉干扰时间。
- 写请求带 draftProtocol=2、planId、stageVersion、version、requestId。以 Socket 真实绑定成员鉴权；最近 128 条请求按计划、成员、ID 去重，同 ID 改载荷拒绝。推进、投放、准备、互换在同一房间锁中读取最新状态。
- 仅两位当前真实队长可领取、投放、准备及读分页，房主不兼任队长不能代操作。交接立即撤销旧权限，保留冻结牌和另一队准备状态，新队长重新确认。
- 私密 interference-pool 接口绑定 planId、stageVersion，单页最多 60 部、no-store。公共候选不扩容，队长视图仅补至多两张已选干扰元数据，不向全员广播几千部作品。
- 队员／旁观仅有匿名普通已选集合，不接收私密归属、保护期、书签、干扰和互换来源。正式棋盘及关联板沿用原权限。
- 旧计划没有 animeDraft.version=2 时使用 v1：180 秒、同阶段干扰、原互换开关，运行中不迁移。老客户端对 v2 写操作得到明确刷新提示，不能用旧协议绕过权限；不强制断开旧房间连接。
- 正式构建默认新建动画局使用 v2，作品池留空，须由房主明确选择；同房间下一局沿用已有快照。设置仅读取轻量预设选项，自定义编辑时才获取完整目录。预设由服务端可信 ID 解析，选项接口不发送完整作品条目和作品 ID 列表；已选池仍保留既有快照字段以兼容客户端。旧版浏览器回归显式使用 VITE_DEFAULT_STAGED_DRAFT=0 测兼容，该测试开关不进入正式构建。经典文字玩法不变。
- 当前内存房间仅保证同进程重连及幂等，没有跨重启恢复。部署停机前复查无活动房间。
