## 新增行为

- 动画题库广场：公开搜索与分页、个人池新建/编辑、公开/私人切换、独立复制、私人收藏、举报去重/限流、管理员隐藏/恢复及处理记录；与文字题库、图片图库分别保留入口。
- 作品池使用结构化 Bangumi ID，服务端校验当前目录。允许保存尚不足开局数量的草稿；实际 5×5/6×6 配置仍校验至少 25/36 个不同系列，不从其他题库补牌。
- 房间按社区池 ID + revision 读取服务端快照。非法客户端 workIds 不能覆盖该快照；新引用拒绝旧版本、无权池和隐藏池；后续修改/隐藏不改变已经配置的局。
- 原浏览器作品池可由用户主动导入社区私人池；复制默认私人，互不影响源池版本。
- 私有身份凭证备份/恢复，可跨设备读取自己的池、收藏与私密复盘；新增独立私密回放页面，准备大厅与连续局保留历史入口。
- 私密编辑仅克隆当前私有状态，避免反复复制整份动画目录；Socket 入口限流，并预留翻牌快照容量。容量不足只拒绝编辑，实际猜牌不会因图谱过满而被中断。
- 角色/结束原因、当前线索/整局图、意图锁定、预测冻结、成员 ACL、公共回放隔离均有专门回归。修正了图谱起点/终点选择器的可访问标签。

## 身份和管理员权限

社区沿用 P2-1 的随机设备凭证：浏览器生成 32 字节随机值；通过 `x-private-key` 请求头提交，服务端以带用途前缀的 SHA-256 派生所有者标识。公开 DTO、链接、举报结果不包含原始凭证或内部所有者标识。昵称只是署名，旧 username-only 会话不能认领其他设备的社区资产。

受凭证绑定的房间身份，即使关联板开关关闭，也禁止仅凭同名登录恢复；原有仅持房间随机 token 的重连仍有效。新设备可主动恢复保存的凭证。没有备份就无法通过昵称找回这些私人数据；输入其他昵称不会更换持有的凭证。已有 users.json、战绩、文字/图片题库不做迁移或覆盖。

管理员使用独立 `ANIME_POOL_ADMIN_KEY`，不按用户名或客户端 role 提权。后台验证配置密钥长度和定长摘要，页面只在当前窗口保存输入。管理员可读举报理由/处理记录，仍不下发举报人身份。公开页和普通池详情不返回举报记录。

凭证是持有者权限，部署时应通过 HTTPS 传输。匿名用户主动丢弃凭证、换新设备或建小号，无法证明其现实身份；同一已知凭证下的卸任队长、角色切换、重连/改名严格保留本局秘密接触限制。

## 给部署 Agent 的配置清单

本节供其他部署 Agent 操作，本 Agent 不执行。

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `ENABLE_MATCH_ANALYSIS` | 0 | 新动画局关联板、意图与私密归档；按局固化 |
| `ENABLE_PREDICTIONS` | 0 | 在启用分析的局内开启观众红/蓝预测；按局固化 |
| `ENABLE_ANIME_COMMUNITY` | 0 | 社区导航与新建/编辑/复制/收藏入口；关闭仍允许读取已有授权池、举报与管理员治理 |
| `ANIME_POOL_STORE_FILE` | 现有进程默认相对路径 | 社区独立 JSON 数据；生产务必明确绝对路径，纳入持久化备份 |
| `ANIME_POOL_ADMIN_KEY` | 空，管理禁用 | 部署 Agent 单独生成至少 32 字符随机值，安全交给管理员；不写入仓库/日志/发布报告 |

服务历史工作目录是 `/opt/codenames-acg/apps/server`，部署 Agent 必须重新核实实际目录及环境变量来源。可将新增社区文件放在该服务已有持久化数据目录，例如 `/opt/codenames-acg/apps/server/data/anime-pools.json`；不改变真实账号/图库路径。

社区文件 `schemaVersion=1`，单进程串行修改，先写临时文件再原子 rename，完成落盘后才替换内存状态。加载格式错误时拒绝覆盖，写盘失败保留旧数据。此存储随磁盘文件保留；房间、基础回放、私密归档仍是内存，私密归档最长七天且进程重启会丢失，不能用社区落盘承诺恢复房间。

发布前：读取本次推送分支及实际提交，确认与线上差异；备份程序、构建、配置及最新用户/图库/社区文件；确认无真实活跃局后按既有机制同步 shared/server/web。用户授权和当前房间状态由部署 Agent 判断，不沿用本文历史检查替代实时核验。

回滚：停止新入口、等待已启用对局完成后恢复上一完整应用版本；保留新社区文件与最新账号/图库，不能用旧备份覆盖上线后新增数据。旧版本不识别社区模块时暂停入口即可，不删除社区数据。部署后分别验收公共基础回放和受鉴权私密复盘，以及社区隐藏/权限边界。
