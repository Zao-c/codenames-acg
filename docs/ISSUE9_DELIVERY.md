## 根因与修复

- 普通队员在锁定组牌期间主动离开会被删出名单，但原逻辑仅在队长离开时解除准备锁；早先安排的离线清理定时器也没有重新检查组牌锁。现在临时断线保留名单与进度；同一私密身份先尝试恢复原席位，再校验新入场限制。真正退出则作废本次准备、清理旧手选/封存数据并回到配置阶段，房主可补人或重新分队。新玩家仍不能进入锁定名单。
- 原导航品牌按钮直接退出房间，路由又被房间状态强制拉回；现在浏览题库、图库、档案、主大厅不退出，全站显示返回入口，大厅本人房间显示“返回房间”。同一玩家多标签共用合法席位，关闭其中一个标签不把其他标签踢出。
- 原登录页没有消费登录成功状态；会话没有按账号及私密凭证隔离，旁观入口会优先尝试旧参赛 token。现在登录与游客入口保留建房/邀请目标，失效重连凭证只进行一次身份恢复回退；旁观与重连分开。切换身份分离私密 key 和房间会话，服务端重连验证 token 与私密主体一致。
- 已选缩略卡原先没有指针拖拽能力。现在复用统一手势，支持鼠标从右向左撤回、触摸长按拖到撤回操作坞、拖入已有卡进行确认更换、手机“更换这张”以及满额选择旧卡。服务端原子替换、10 秒保护、最后 20 秒限制和干扰权限不变。星号使用即时反馈并在未同步时回退。
- 正式对局使用紧凑只读成员栏及独立聊天滚动；手机棋盘/玩家/聊天页签保留。动画卡片右键或手机长按抬手后打开私人预判；预判按房间、局、参与者和私密 key 存在本地，不发往服务器，不翻牌。作品预览及猜牌二次确认保留。
- 结算改为独立 `MatchResult`：胜负和比分、称号、回顾、复盘入口及折叠明细。下一局只有入口，点击后打开完整宽度准备工作区。手机结算使用正常全站导航，避免出现无对应面板的页签。
- 关联板改为 `GraphCanvas`：方形线索、圆形本局作品、直接拖动节点、拖连接点/点击连接、编辑及删除节点/边、平移、滚轮/双指缩放与重置。继续使用原 GraphOperation、版本校验和权限结构，队员共享、队长只读、私人意图及复盘权限均保留。编辑失败后重新同步并保留错误提示；每秒 5 次限制保留。
