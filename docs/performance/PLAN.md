# 多人卡顿修复与图片分发方案

基线：正式生产 `211401ee46bf205333d5a220d057a6fa09c71200`。性能代码在独立 `codex/cipai-performance` 工作区。此文档不表示已部署；没有开通云服务、上传 COS 对象、读取密钥或重启生产。

## 已核实的现象

用户报告的时间为北京时间 2026-10-18 20:30—23:30。当时仍为 Round 7；Round 8 于 23:51 首次部署，最终补丁于 2026-10-19 00:39 部署。

该时段全站 nginx 记录 292 次目录请求，响应体合计 820,175,329 字节。此数字包括全站请求，不能全部归属于用户的单个房间。当前目录 4954 部，JSON 3,314,023 字节；JSON 原先未压缩且禁止缓存。历史 sysstat 的十分钟采样平均 CPU 空闲 94.93%，不能据此排除瞬时停顿，但没有持续算力耗尽的证据。

原有组牌状态每次逐连接全量发送，并再次广播全站大厅列表。候选池最多 180 部；头像使用内嵌 data URI。准备面板的时钟每 200ms 刷新并重新处理候选列表。4893 部当前封面直连 lain.bgm.tv，另有 61 部缺封面；当时浏览器侧失败原因没有保留，不能把所有缺图都断言为图站故障。

## 当前隔离代码的改动

- 首页改为 24 条精选摘要；完整目录只在房主配置或编辑目录时读取，身份隔离的单次请求合并与 5 分钟内存缓存避免跨组件重复读取；写操作清缓存，HTTP 私有缓存按 x-private-key 区分并可条件验证。API 使用标准 gzip 压缩。
- 图片直连保持为默认路径。仅在原图较慢/失败时试备用，不取消仍在等待的原始图片；备用只有加载成功后才替换。可见范围触发，备用每页一条并发，离开页面取消排队。本站备用仅限服务器目录已知的 Bangumi 图片，验证固定 HTTPS CDN、禁止重定向、限制 MIME、2MB、超时和像素数。
- 本站备用磁盘缓存可重新生成，128MiB 上限；相同冷缓存请求合并。下载最多 4 并发；小头像转换不排在远程图片下载队列后。账户及业务原文件不变。
- 房间和大厅传输的头像改为哈希静态 URL。原有 data URI 仅留在账户/业务存储，避免每个操作重复发送。内存索引最多 512 项/24MiB；磁盘缓存独立于业务文件。
- 新客户端先协商增量协议。每个连接先得到完整的、已脱敏的独立视图；随后只发送改变字段，候选 metadata、棋盘和成员未变时不重复发送。序号断档时请求全量恢复，权限变化会删除失去权限的字段，旧客户端仍得到全量。大厅更新合并 150ms，不延迟游戏动作的确认。
- 候选卡内部 memo；事件转发读取最新回调，避免缓存旧的领取/撤回/替换权限。时钟改为每秒更新，卡片只在自己的内容、权限或保护倒计时改变时重绘。原有鼠标拖拽、350ms 触屏长按、保护期、抢夺、干扰、替换和所有服务器规则保持。
- 已获得账户和 session 的交互登录不再立即重复登录一次；页面冷启动仍向服务器验证账户，不跳过权限验证。

## AniMatch 只读参考

检查 `/opt/Animatch/animatch` 的封面选择、COS 缓存、预热、失败回退和当前数据库聚合值，没有读取配置密钥。

实际 41,581 部作品中 588 部有 COS 封面；不是全库都已迁移。588 张平均 48,753 字节，中位数 25,424，P95 119,584，合计 28,666,564 字节。词牌目录与这批作品按 Bangumi ID 重合 223 部；重合 ID 不等于确认封面相同，复用前仍须核对原始 source URL 和当前公开读取权限。

三组服务器侧同作品抽样：COS 200/48,232B/524ms、200/89,632B/564ms、200/62,748B/207ms；对应原图站三个请求均在 10 秒 TLS 握手超时。这是少量服务器侧样本，不是各运营商浏览器速度保证。

另取 12 张 COS 图片在内存中缩放，平均：现有图 26,246B，200px WebP(q78) 11,203B，400px WebP(q82) 20,773B。样本含一张很小的占位图，不能当作全库严格平均值。

## 建议最终图片方案

离线或独立后台队列下载 → 一次性生成 200px 候选图、400px 棋盘图及清晰导出图 → COS → 浏览器。新增作品后台补齐；只有上传/校验成功的映射才进入使用；保留源 URL，支持回退。避免玩家进入页面时现场下载/压缩全库，避免让 Node 游戏进程长期转发所有图片。

当前小规模先使用 COS 默认 HTTPS 直出，已有已备案图片域名时可接国内 CDN。COS/CDN 故障只影响图片路径，不能阻塞开房、组牌和线索提交；已经显示的图不能因超时提示被卸载。只预热本局可见候选及邻近屏幕，不下载 4954 张全库。

本次没有将其他项目的 COS 密钥复制到词牌，没有修改 AniMatch，没有执行对象上传或付费资源变更。COS 主图映射、迁移队列和 CDN 配置属于下一步实际接入工作，尚未上线或声称完成。

## 流量与费用估算

计费依据于 2026-10-19 查询的官方价格页；地域、资源包和账号折扣会改变实际费用。

- COS 当前公开示例价：外网下行 0.5 元/GB，CDN 回源 0.15 元/GB，标准存储读取 0.01 元/万次，示例地域存储 0.118 元/GB/月。不同计费项不能混用资源包。
- 以当前 588 张平均值外推，4954 张单版本约 242MB；多尺寸和高清副本会增加存储。最终以全量转换报告为准。
- 八人 × 180 候选 × 11.2KB，加八人 × 36 棋盘 × 20.8KB，首次加载约 22MB。按 20—40MB/八人局保守预算；完全新图、每天六局、30天约 4—7GB/月，COS 直出流量约 2—4元，加存储和请求费用。实际浏览器命中缓存、未滚到屏幕外的小图会减少流量；反复清缓存、更多玩家和外部访问会增加流量。
- 这些是按假设用量计算的图片费用，不是整个云账户的月账单保证，不包含游戏服务、API、回放导出大图和既有其他项目费用。
- COS+CDN 的账单包括 CDN 下行、COS 回源及请求，HTTPS 请求可能另计。不能只看 CDN 流量包价格，也不能认为 CDN 命中后玩家流量免费。

## 验收边界和发布条件

本机单元、回归、浏览器和负载数据是可复现证据，不是三小时真实公网体验保证。不能用功能测试通过替代长时性能验收，也不能把八 Socket 客户端等同于八台真实浏览器。

发布前需要：规则/类型/构建/多人回归通过；八浏览器与头像、手机限速和重连通过；原图迟到 61 秒、缓存失败仍自动恢复通过；预热及 COS 映射另行验证后才切主图。正式切换仍要重新检查活跃房间、备份、数据一致性和回滚点。内存房间重启失效的原限制仍在，不允许直接覆盖业务数据。
