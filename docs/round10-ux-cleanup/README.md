# 词牌结社 · 精简文字与用户文字题库隐私收回

基于 2026-10-22 PR #20 `8a4d281` 单独分支。本 PR 仅为开发与评审，**不自动部署、不重启服务、不合并**。

## 已实施

- 首页去掉无意义说明、重复三玩法标签、创建房间辅助文字和废弃的「高级建房」入口；无公开房间时隐藏筛选，正常房间列表保留。
- 准备大厅去掉重复的身份教学、英语装饰标题和三步操作教程；只有人数、队长、历史轮换系列不足或离线等真正阻止继续的条件，才显示必要的原因。对禁用主按钮保持可读对比度。
- 房间设置保留两栏结构，右侧四张封面预览、作品/系列/历局排除统计及操作入口**原封不动**。移除「设置如何显示给队友」说明卡与规则小字。去掉与组牌流程不一致的固定「选牌期间干扰」冗余项。
- 用户文字题库、图片图库按内容优先的单列列表布局；标题允许换行，不再为多个按钮被截断。次要操作收进「更多」菜单，删除保留确认。
- 个人档案强调当前佩戴称号，而非无条件突出第一条；删重复说明。
- 服务端首次加载历史用户数据时，将所有**现有公开用户文字题库**收回为私有；只影响用户文字题库，不改内置系统题库、动画作品池和图片图库。
- 迁移前在服务器用户存储文件旁保存带时间戳的副本，持久化一次性版本标记。公共题库列表不再列出这些记录，旧公开详情 URL 返回 404，公共文字接口返回 `Cache-Control: no-store`。
- 用户后续**主动点击公开**仍允许发布；通过 `publishWordPackIds` 显式提交，仅服务器确认所有者的公开意图。旧标签页的普通编辑不能无意重新公开。

## 进一步确认的问题

- 图片图库「用于开房」原本只是进入 `/create`，并没有把该图库自动绑定到新房间。这是独立的图片/揭幕准备交互问题；本 PR **未伪造自动选池行为**，后续需要独立处理。
- 公共题库即使在服务器撤销后，也无法撤回他人此前已下载的词条。后台需在迁移前核对备份位置与存储访问权限。
- 个人偏好中的大量同级按钮还可继续归类，但这轮未改房间管理权限和全站路由。
