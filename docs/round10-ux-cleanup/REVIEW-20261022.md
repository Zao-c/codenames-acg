## 已复现并修复

1. **前端无法编译**：设置概览删除说明文字后残留 `{poolId!=='current'&&}`，`npm run typecheck` 报 TS1109。移除这个不完整表达式，保留原有作品池封面与统计。修复提交 `a005fee`。
2. **隐私迁移可能覆盖有效备份**：主用户文件为可解析 JSON、但形状为 `{users:null}` 时，被识别为空库；首次读取触发迁移，将主文件及原本包含账户的 `.bak` 均写为空用户列表。隔离模拟已复现。现在先校验用户数据库结构，异常主文件回退到有效备份；主备均异常则拒绝读取且不写入。增加四种异常结构、双损坏及合法空库的回归检查。修复提交 `019aeea`。
3. **旧 HTTP 测试未适配主动公开接口**：原测试仅传 `isPublic:true` 即断言公开。现明确验证普通保存仍为私有、旧详情返回 404 且不缓存、非法公开参数返回 400，再通过 `publishWordPackIds` 主动公开，保留公开题库后续全流程。测试提交 `4fb75ec`。
